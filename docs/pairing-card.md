# BlakSync pairing card

Print this page. Keep it with the office node or the field bag. No Syncthing jargon without a plain word next to it.

## On this device

1. Open BlakSync (http://127.0.0.1:8385 or the tray icon → Open BlakSync).
2. Open **This device**.
3. Show the QR, or read the six-character code, or read the long device ID if you must.

## On the other device

1. Open **Remote devices** → **Add device**, or open **Pending** if it already knocked.
2. Scan or paste the ID, or type the six-character code if the other machine is already waiting on the local network.
3. Read the access note. Accept only if you invited this machine.

## After pairing

Pairing lets the machines talk. It does **not** copy a folder. Share each folder on purpose. The other side must accept the folder and choose a local path.

## If something goes wrong

- **Pause** stops new copies without breaking the pairing.
- **Unshare** stops future copies. Files already received stay on both disks.
- A lost laptop is not wiped remotely. Use **Revoke device**, then treat that disk as exposed if it was unlocked.
